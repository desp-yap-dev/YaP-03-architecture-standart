| Код | Требования                         | Комментарий  |
|-----|------------------------------------|--------------|
| F   | Функциональные (Functionality)     |              |
| F1  | На сайте новый клиент видит список доступных депозитов с актуальными ставками                                |              |
| F2  | Клиент может подать заявку на депозит на сайте, оставив свой номер телефона и ФИО, после чего с ним связывается менеджер кол-центра                               |              |
| F3  | В интернет-банке клиент видит список доступных депозитов с актуальными ставками и персонализированные ставки                        |              |
| F4  | В интернет-банке клиент клиент может указать счет и сумму депозита и подать заявку на открытие депозита с подтверждением СМС-кодом                                |              |
| F5  | Сотрудники кредитования и депозитов ведут работу со ставками в АБС                               |              |
| F6  | Менеджер бэк-офиса обрабатывает заявку на открытие депозита в АБС                                |              |
| F7  | Клиент получает СМС-уведомление после открытия депозита                                |              |
| U   | Удобство использования (Usability) |              |
| U1  | Удобный интерфейс для клиента на сайте и в интернет-банке                                |              |
| U2  | Использование корпоративных дизайна, цветов и брендинга                                |              |
| R   | Надёжность (Reliability)           |              |
| R1  | Доступность - 24/7, SLA - 99,9%                                |              |
| R2  | Необходим резервный ЦОД (переключаться в случае сбоев)                                |              |
| R3  | Реализован мониторинг состояния работоспособности интернет-банка и сайта                                | Необходимо быстро реагировать на возможные сбои в работе             |
| P   | Производительность (Performance)   |              |
| P1  | Отклик по всем операциям - максимально быстрый (не более 0,5 сек)                               |              |
| P2  | Загрузка справочных данных - менее секунды                                |              |
| P3  | Возможность горизонтального масштабирования компонентов интернет-банка                               |              |
| S   | Поддерживаемость (Supportability)  |              |
| S1  | Использовать те технологии, в которых у сотрудников есть экспертиза                                |              |
| S2  | Ведение документации                                |              |
| +R  | + Ограничения (Restrictions)       |              |
| +R1 | Передача данных с сайта и интернет-банка должна быть зашифрована, т.к. передаются чувствительные данные                                |              |
| +R2 | Реализация функционала работы с смс - силами команды разработка банка                               |              |
| +R3 | В качестве СУБД - MS SQL и Oracle                               |              |
| +R4 | Интернет-банк НЕ работает напрямую с API АБС                              |              |
| +R5 | Масштабирование АБС возможно только вертикально                               |              |
| +R6 | База данных системы АБС перегружена                               | Требуется вертикальное масштабирование либо иная оптимизация              |
| +R7 | Некоторые справочные данные грузятся более секунды                               | Требуется оптимизация/рефакторинг              |
| +R8 | В случае необходимости использования очередей - kafka                               | Ограничение: текущая версия платформы несовместима с kafka              |
